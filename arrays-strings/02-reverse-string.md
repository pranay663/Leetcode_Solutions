## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I used the two-pointer technique to reverse the string in place.
One pointer starts from the beginning and the other from the end, and their elements are swapped until they meet.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

I tested the solution locally using a normal string and a single-character edge case before submitting it on LeetCode. The solution was accepted by LeetCode.

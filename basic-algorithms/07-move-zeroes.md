## Problem: Move Zeroes (Easy)

**Link:** https://leetcode.com/problems/move-zeroes/

### Approach

I moved all non-zero elements to the front of the array while keeping their original order.
After that, I filled the remaining positions with zeroes.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

I tested the solution locally using an array containing multiple zeroes and an array with zeroes at the beginning. The solution was then accepted by LeetCode.
